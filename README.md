# Practice Portfolio

This repository combines my learning practice work across three core technologies:

- NumPy: array creation, indexing, broadcasting, and numerical computations
- Pandas: DataFrames, row/column operations, and data exploration
- React: components, props, state, forms, hooks, and styling

The goal of this project is to keep all practice work in one place for easier review and portfolio presentation.

## Repository structure

- `numpy/` — NumPy practice notebooks and examples
- `pandas/` — Pandas practice notebooks and data exercises
- `react/` — React practice app and frontend examples

## How to use

1. Open the folder for the topic you want to review.
2. Run the notebooks in `numpy/` and `pandas/` with Jupyter.
3. Start the React app in `react/` with Vite.

This repo was created as a single combined portfolio repo for easier understanding and access to all learning work.
